# Baba Is You

[Setup Guide](setup_en.md)

## What does randomization do to this game?

Every pushable word is an item. If you don't have the item, the word appears grey with red ? particles and becomes immovable (STILL property). You can still form rules with locked words. Other items include:
- Blossoms: Needed to open locked gates on the world map
- Blossom Petals: Worth 1/8 of a Blossom.
- World Keys: Prevent access to subworlds like Lake.
- Bonus Orbs: All three are needed to unlock Gallery in Center.
- Speck: A filler item that does nothing.

Location checks include:
- Winning each level
- Clearing each subworld
- Fully completing each subworld (optional)
- Collecting a Bonus
- Transforming a level into an object (optional)

In addition, you can shuffle where each level appears.

## What is the goal for this game?

There are several goals available:
- Both the Normal and True endings
- Reaching a certain area in the game
- Collecting a certain amount of Blossoms
- Winning a certain number of levels

## What does another world's item look like in Baba Is You?
Items do not have any visual appearance.

## When the player receives an item, what happens?
You will get a popup message when you receive an item, but not when you send an item as of right now.
